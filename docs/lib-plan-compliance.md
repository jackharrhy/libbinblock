## Definition of success

|   # | Result                                                                                                                                                            |
| --: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   1 | Direct C construction and the C BinScript frontend converge on the same immutable graph and canonical raster backend; both paths have pixel tests.                |
|   2 | Public headers depend only on C standard headers and BinBlock declarations; JSON, TypeScript, browsers, filesystems, engines, and graphics SDKs stay in adapters. |
|   3 | The CPU raster profile is documented and tested for exact arithmetic, historic compatibility, transparent RGB, and declared bounded cases.                        |
|   4 | Collection cardinality, indexed slicing, limits, and render-on-demand are lazy and covered by allocation-observing tests.                                         |
|   5 | One generated, reviewable BinScript file describes all 4,312 outputs; generic recipes and explicit compatibility assets/aliases are visible in source.            |
|   6 | The manifest and executable TSV classify all files and the comparator produces aggregate plus per-file evidence.                                                  |
|   7 | The production notebook calls only the Wasm/C compiler and hydrates reference content on demand by graph content ID.                                              |

## Reference contract snapshot

The locked 4,312 rows currently have these equivalence classes:

| Equivalence        | Count |
| ------------------ | ----: |
| Pixel exact        |    64 |
| Alpha-only exact   |    18 |
| Bounded difference |    48 |
| Raster fallback    | 2,956 |
| Pixel alias        |   975 |
| Byte alias         |   251 |

Provenance is 50 fully analytic outputs, 80 analytic downscales from canonical
asset graph nodes, 2,956 raster assets, 975 pixel aliases, and 251 byte aliases.
The full comparator result is 4,312/4,312 matched, 60,750 differing channels in
bounded contracts, and a maximum observed per-channel error of 13.
